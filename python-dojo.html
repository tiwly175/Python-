Python คืออะไร

รู้จักภาษาที่อ่านง่ายสุดในโลกโปรแกรมมิ่ง

Python ถูกออกแบบให้อ่านเหมือนภาษาอังกฤษ ผู้สร้างต้องการให้คนที่ไม่เคยเขียนโค้ดอ่านโค้ดคนอื่นเข้าใจได้ทันที นี่คือเหตุผลที่มันกลายเป็นภาษาแรกที่คนทั่วโลกเลือกเรียน

ภาษาเดียวใช้ได้กับงานหลากหลาย — สคริปต์, วิเคราะห์ข้อมูล, เว็บแอป (Instagram, Spotify ก็ใช้)

  1. เช็ก python --version
  2. ปิด-เปิดเทอร์มินัลใหม่

ตัวอย่างการใช้งาน

hello.py
# hello.py print("สวัสดี Python")

พิมพ์บรรทัดนี้

terminal
$ python hello.py สวัสดี Python

รันผ่าน CLI

⚠ จุดที่มือใหม่พลาดบ่อยถ้าพิมพ์ python ไม่เจอ ลอง python3

เทคนิคที่ควรรู้

  • ตั้งชื่อไฟล์ .py ภาษาอังกฤษ
  • รันโค้ดบ่อย ๆ ทุกครั้งที่แก้
  • Terminal > New Terminal ใน VS Code

$ ลองด้วยตัวเอง
